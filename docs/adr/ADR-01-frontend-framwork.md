# ADR-01: Frontend Framework

## Decision
Use **React + TypeScript + Vite** for the RescueRoute frontend.

## Why
- Fast development and build process
- Type safety with TypeScript
- Component-based architecture
- Simple integration with Leaflet and REST APIs
- Suitable for future scalable UI development

## Current Status
Implemented.

## Scope
All frontend pages, components, routing, map UI, forms, and API integration use this stack.
